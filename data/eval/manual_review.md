Модель: fallback chain через OpenRouter (`nvidia/nemotron-3-super-120b-a12b:free` в роли основной).

**Средняя оценка: 4.2 / 5**

## Известные ограничения

- **2 провала retrieval из 20** (#14 equipment_barbell, #19 substitution) — модель путает близкие по теме документы.
- **Утечка thinking** иногда случается у reasoning-моделей, но фильтр в `llm_client.py` отсекает большинство случаев.
- **`graph?` в источниках** — модель галлюцинирует, если графовые факты не имеют doc_id.

## Идеи для улучшения

- Reranker (cross-encoder) поверх Chroma для повышения Hit Rate.
- Query rewriting через LLM для запросов с «заменить».
- Отдельный doc `substitutions.md` с явным списком замен.
- Post-processing источников: заменять `graph` на `graph_facts`.
