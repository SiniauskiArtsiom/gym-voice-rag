# Программа StrongLifts 5x5

Три тренировки в неделю, чередуя A и B.

Тренировка A: приседания 5x5, жим лёжа 5x5, тяга штанги в наклоне 5x5.
Тренировка B: приседания 5x5, жим стоя 5x5, становая тяга 1x5.

Прогрессия: +2.5 кг каждую тренировку, пока получается.
При трёх неудачах подряд — снижай вес на 10%.
Программа для новичков, фокус на базовых движениях.
