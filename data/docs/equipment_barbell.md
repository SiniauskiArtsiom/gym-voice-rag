# Оборудование: штанга

Штанга — основной инструмент для базовых упражнений.
Стандартный олимпийский гриф весит 20 кг, женский — 15 кг.

Основные упражнения: приседания, жим лёжа, становая тяга, жим стоя,
тяга в наклоне.

Для новичка достаточно штанги, стойки и набора блинов.
Обязательно используй замки для фиксации блинов.
