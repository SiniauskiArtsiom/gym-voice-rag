# Прогрессивная перегрузка

Прогрессивная перегрузка — главный принцип роста мышц и силы.
Без увеличения нагрузки тело не будет адаптироваться.

Способы:
- увеличить рабочий вес;
- увеличить количество повторений;
- увеличить количество подходов;
- уменьшить отдых между подходами;
- улучшить технику.

Для новичка: +2.5 кг на штанге или +1 повторение каждую неделю.
Прогресс должен быть постепенным — не более 5–10% в неделю.
